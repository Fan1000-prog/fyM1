# fyM1 v0.1 Implementation Plan

> **For agentic workers:** Execution method chosen by the owner: **Claude Code agent team** (named teammates, shared task list, one branch + worktree per task, PR + fresh reviewer per PR). Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Automation (owner, 2026-10-17):** agents do every non-Malagasy step, including driving Colab via Playwright (Run all, reconnect, read outputs) and picking the base model from the measured table. The owner only logs in (Google, Hugging Face, Facebook) and reviews Malagasy-language items: data samples, identity/refusal lines, test prompts, the 20-answer ratings, arena instructions.

**Goal:** Ship fy-m-1 v0.1 (moved from 2026-10-17 to when the Messenger export is in; see "Changes from the plan") — an open 7–12B model QLoRA-tuned on a free Colab T4 to chat in everyday Malagasy — with a demo, a rating link, a public repo and a short paper.

**Architecture:** Local Python package `fym1` (data cleaning, eval metrics, trimming) tested with pytest on the laptop. GPU work runs in Colab notebooks that pull code from GitHub and data/checkpoints from private HF repos, and push results back to HF. Two Gradio Spaces: `fyM1-chat` (GGUF on free CPU) and `fyM1-arena` (blind A/B votes → private HF dataset). Paper is LaTeX built locally with tectonic.

**Tech Stack:** Python 3.11 (uv), pytest, huggingface_hub, datasets, ftfy, fasttext (GlotLID), sacrebleu; Colab: Unsloth + TRL + bitsandbytes; llama.cpp GGUF via Unsloth; Gradio + llama-cpp-python; LaTeX (tectonic).

**Spec:** `docs/superpowers/specs/2026-10-17-resaka-design.md` (§7 supersedes earlier sections where they conflict; name is fyM1).

## Global Constraints

- Raw Messenger export stays in `~/malagasy-data/raw/`. Never copied into the repo, Colab, or any HF repo. `.gitignore` blocks the root `/data/` folder (root only — `src/fym1/data/` is code), `*.zip`, `.env`.
- Only anonymised, owner-approved data leaves the laptop, and only to the **private** HF dataset `Fan1000-Prog/fyM1-chats`.
- Budget $0. No closed-API (Claude/GPT/Gemini API) outputs in training data. Identity/refusal lines are written or rewritten by the owner.
- Base-model license governs model license + naming; code is Apache-2.0.
- Style target: everyday Malagasy with French mixing, texting spelling, slang, emoji. A reply "drifts" only if it is a full French or English sentence(s) with no Malagasy.
- Name (updated, spec §7.5): public name `fy-m-1`; model `Fan1000-Prog/fy-m-1-<size>`, GitHub `Fan1000-prog/fy-m-1` (recreated clean at release), Spaces `Fan1000-Prog/fy-m-1-chat`, `Fan1000-Prog/fy-m-1-arena`. Private (names unchanged): `Fan1000-Prog/fyM1-chats` (dataset), `Fan1000-Prog/fyM1-ckpt` (model), `Fan1000-Prog/fyM1-votes` (dataset).
- System prompt identity: helpful Malagasy assistant trained by **Fan's lab** (Malagasy wording approved by owner).
- GitHub repo is created **private** and flipped public only at release (Task 9) — so nothing leaks while building.
- No AI attribution anywhere. Every change: branch + worktree `../fyM1-<topic>`, PR, fresh reviewer, merge when clean.
- Every number in README/paper/model card comes from a results file in `results/` produced by a script in the repo. Pending results are labelled "pending (v0.2)".

## Review Focus

1. **Messenger quirks** — mojibake (`Ã©`), messages with only a photo/sticker/reaction, unsent messages, `content` missing: parser must skip non-text cleanly, not crash or emit empty turns. (Test in Task 2.)
2. **Names inside text** — participants' names and nicknames appear inside message bodies, lower-cased or shortened ("Nirina" → "nirin"): anonymiser must replace them, not just the sender field. (Test in Task 2.)
3. **Malagasy-French mixing** — "Mety be zany, lancer-na fotsiny😂" must count as Malagasy (kept, not drift); "Ok merci, à demain" counts as drift. (Test in Task 3.)
4. **Colab disconnect mid-run** — rerunning the training notebook must resume from the latest checkpoint in `fyM1-ckpt`, not restart or overwrite. (Test in Task 4.)
5. **Arena double-voting / empty input** — a rater refreshing or submitting without choosing must not write a vote. (Test in Task 6.)

### Task 3: Eval set + metrics (teammate: `eval`)

**Status:** done (#4; follow-up #15).

**Files:** `src/fym1/eval/lang.py`, `src/fym1/eval/metrics.py`, `src/fym1/eval/judge_rubric.md`, `eval/prompts.jsonl`, `tests/eval/test_*.py`.

**Interfaces (produces):**
- `is_malagasy(text: str) -> bool` — GlotLID (`cis-lmu/glotlid`, fastText) label in `{plt,skg,tdx,xmv}_Latn` (GlotLID has no `mlg_Latn`), plus a Malagasy word-share check (common Malagasy words, ≥10% of words; look-alike English/French words such as `be, no, any, e, eh` excluded) so code-mixed lines pass.
- `drift_rate(responses: list[str]) -> float` — share of responses where `not is_malagasy(r)`.
- `leak_rate(responses: list[str], train_texts: list[str], n: int = 8) -> float` — share of responses containing any word 8-gram found in training texts (lower-cased, punctuation stripped).
- `eval/prompts.jsonl` — 150 fresh prompts `{"id","prompt","category"}`; categories: greetings/small talk (50), everyday questions & advice (40), banter/humour (20), facts in casual tone (20), identity & safety (20). Drafted by `eval`, edited/approved by the owner. Public.
- `judge_rubric.md` — 1–5 naturalness ("sounds like a real Malagasy person texting"), 1–5 correctness; published. Judging done by in-session Claude agents (zero cost), clearly labelled as such in the paper.

- [x] Tests first: `is_malagasy("Mety be zany, lancer-na fotsiny😂") is True`; `is_malagasy("De ahoana?") is True`; `is_malagasy("Ok merci, à demain") is False`; `is_malagasy("Sure, I can help with that.") is False`; `drift_rate(["Salama!", "Hello there"]) == 0.5`; `leak_rate(["a b c d e f g h"], ["x a b c d e f g h y"]) == 1.0`; `leak_rate(["a b c"], ["a b c d e f g h"]) == 0.0` (reply too short for n=8); training texts with no 8-grams raise.
